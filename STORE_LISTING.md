## App Name

THE SYSTEM: LEVEL UP

## Short Description

Daily fitness planning, workout logging, readiness, and progress tracking.

## Full Description

THE SYSTEM: LEVEL UP is a dark sci-fi fitness command center for people who want a clear answer every day:

What should I do today, why this, and how does it move me forward?

The app combines workout planning, set logging, readiness context, calendar rhythm, quests, progression, and profile statistics into one local-first training system.

Core features:

- Today Order: a daily training/rest/recovery decision based on your cycle, readiness, and logged progress.
- Workout logging: fast set completion, incomplete-set states, finish report, progression verdict, and next-session targets.
- System/Cycle tab: configure training days, active cycle, equipment, and workout structure.
- Calendar: see planned training days, completed work, missed days, and daily events.
- Statistics: weekly summary, progression proof, annual progression, body/profile trends.
- Profile: personal metrics, rank, level, streaks, and settings.
- Optional Health Connect support: sleep-session data can improve readiness context when you grant permission.
- Local fallback mode: the app remains useful without Gemini/AI.

THE SYSTEM: LEVEL UP is not a medical app. It does not diagnose, treat, or prevent disease and does not replace professional medical advice.

## Data Safety Draft

Data collected/processed locally:

- Health and fitness: workout logs, exercises, sets, reps, weights, body metrics, readiness inputs, Health Connect signals when permission is granted.
- Personal info: optional display name and avatar URI.
- App activity: app-generated progress, XP, quests, streaks, calendar training state.

Data sharing:

- Current public release: no ads, no custom cloud account sync, no sale of personal data.
- Gemini/AI is disabled in release. If future release enables AI/cloud processing, Data safety answers must be updated before launch.

Security and deletion:

- Sensitive Room database files are excluded from Android automatic cloud backup/device transfer.
- Users can create explicit JSON backups inside the app.
- Data can be removed by clearing app data/uninstalling; user-created backup files remain under user control.
