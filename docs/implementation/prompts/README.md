# Промпти перенесені

З 2026-10-12 всі повні P/R-промпти живуть в одній
[нумерованій папці](../../remaster/prompts/). Тут немає другої робочої копії.

[QUEUE](../../remaster/QUEUE.md) містить точний порядок, поточний етап і посилання
за незмінними P/R IDs. Наприклад, колишній `01-safe-history-edits.md` тепер
[01-P01-safe-history-edits.md](../../remaster/prompts/01-P01-safe-history-edits.md).
Статуси та evidence P-завдань залишаються у [PROGRESS](../PROGRESS.md).
